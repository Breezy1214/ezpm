  <name>Task 1: Implement run_init wizard with file detection and alias handling</name>
  <files>rust-src/commands/init.rs, rust-src/commands/mod.rs</files>
  <action>
Create `rust-src/commands/init.rs` with a `pub fn run_init() -> Result<()>` function implementing the full init wizard.

**Imports needed:**
```rust
use anyhow::{Context, Result};
use inquire::{Confirm, MultiSelect, Select, Text};
use std::collections::HashMap;
use std::path::Path;

use crate::config;
use crate::services::config_gen;
```

**Wizard flow (sequential prompts — CONTEXT.md "all-at-once wizard" means one continuous flow, not a form):**

1. **Detect existing files** (INIT-02):
   - Check for: `ezpm.toml`, `.darklua.json`, `rokit.toml`, `wally.toml`, `default.project.json`
   - Print detection messages: "Detected rokit.toml", "Detected .darklua.json", etc.

2. **Handle existing ezpm.toml**:
   - If `ezpm.toml` exists, use `Confirm::new("ezpm.toml already exists — overwrite?").with_default(false).prompt()?`
   - If user declines, print "Aborted." and return Ok(()).

3. **Detect project name** from existing `default.project.json`:
   - If `default.project.json` exists, try to read it, parse as JSON, extract `name` field.
   - Use detected name as default, or "my-roblox-game" if not found.

4. **Prompt for project name** (INIT-01):
   - `Text::new("Project name:").with_default(&detected_name).prompt()?`

5. **Prompt for source directory** (INIT-01):
   - `Text::new("Source directory:").with_default("src").prompt()?`

6. **Handle existing config files per-file** (INIT-02 — CONTEXT.md "per-file prompt"):
   - For rokit.toml:
     - If exists: `Select::new("rokit.toml already exists —", vec!["keep", "overwrite"]).prompt()?`
       - If "overwrite", write new rokit.toml.
     - If not exists (INIT-06): `Confirm::new("No rokit.toml found — create with default tools?").with_default(true).prompt()?`
       - If confirmed, call `generate_rokit_toml()` and write to file.
   - For default.project.json:
     - If exists: `Select::new("default.project.json already exists —", vec!["keep", "overwrite"]).prompt()?`
       - Track whether to regenerate.
     - If not exists: will be generated (INIT-07).

7. **Handle alias import or defaults** (INIT-03, INIT-05):
   - If `.darklua.json` exists:
     - Import aliases using `config::import_aliases_from_dir(Path::new("."))`
     - Present `MultiSelect::new("Select aliases to import:", alias_names).with_all_selected_by_default().prompt()?` (CONTEXT.md: "checklist for user to pick which to import")
     - Filter imported aliases to selected names only.
   - If no darklua.json or no aliases imported:
     - `Confirm::new("Use default aliases (Client, Server, Shared, Packages, ServerPackages)?").with_default(true).prompt()?`
     - If confirmed, create default 5 aliases (INIT-05):
       ```
       Client -> {src}/client/
       Server -> {src}/server/
       Shared -> {src}/shared/
       Packages -> Packages/
       ServerPackages -> ServerPackages/
       ```

8. **Normalize alias paths** (Pitfall 5): ensure all alias paths end with `/`.

9. **Create scaffolding directories** (INIT-04):
   - For each alias whose path starts with the src prefix: `std::fs::create_dir_all(&path_no_slash)?`
   - Print "Created directory: {path}" for each new directory.

10. **Write ezpm.toml** (INIT-05):
    - Call `config::save_ezpm_toml(Path::new("."), &project_name, &src_dir, "darklua_build", &aliases)?`
    - Print "Generated ezpm.toml".

11. **Regenerate .darklua.json and .luaurc** (CFG-06, CFG-07 via INIT workflow):
    - If aliases is not empty: call `config_gen::write_config_files(Path::new("."), &aliases)?`
    - Print "Generated .darklua.json" and "Generated .luaurc".

12. **Generate default.project.json** (INIT-07):
    - Only if it did not exist or user chose "overwrite".
    - Call `generate_rojo_project(...)` (see Task 2 helper).
    - Write to `default.project.json`.
    - Print "Generated default.project.json".

13. **Print completion message**: "Project initialized! Run `ezpm serve` to start developing."

**Helper: `generate_rokit_toml() -> String`** (INIT-06):
Match the Luau `toolchain.generateRokitToml()`. Use hardcoded DEFAULT_TOOLS array:
```rust
const DEFAULT_TOOLS: &[(&str, &str)] = &[
    ("darklua", "seaofvoices/darklua@0.17.3"),
    ("lune", "lune-org/lune@0.10.4"),
    ("rojo", "rojo-rbx/rojo@7.6.1"),
    ("wally", "UpliftGames/wally@0.3.2"),
    ("wally-package-types", "JohnnyMorganz/wally-package-types@1.6.2"),
    ("selene", "Kampfkarren/selene@0.30.0"),
    ("stylua", "JohnnyMorganz/StyLua@2.3.1"),
];
```
Generate TOML string with header comment, `[tools]` section, and all tool entries.

**Helper: `generate_rojo_project(project_name: &str, aliases: &HashMap<String, String>, src_prefix: &str) -> String`** (INIT-07):
Map known aliases to Rojo service locations using `serde_json::json!`:
- `Client` -> `StarterPlayer.StarterPlayerScripts.Client`
- `Server` -> `ServerScriptService.Server`
- `Shared` -> `ReplicatedStorage.Shared`
- Unknown src aliases -> `ReplicatedStorage.{AliasName}`
- Non-src aliases (Packages, ServerPackages) are skipped.
Strip trailing slash from path values for `$path` entries.
Return `serde_json::to_string_pretty(&project_json)` with trailing newline.

Add `pub mod init;` to `rust-src/commands/mod.rs`.
