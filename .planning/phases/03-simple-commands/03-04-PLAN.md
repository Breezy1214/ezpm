**`pub fn alias_add() -> Result<()>`** (CFG-02):
Implements CONTEXT.md "side-by-side prompt showing both alias name and path fields together on one screen" as two sequential Text prompts (the standard inquire pattern — see Research Open Question 3):

1. Prompt alias name: `Text::new("Alias name (e.g., Client):").prompt()?`
   - If empty, print "Aborted." and return Ok.
2. Prompt alias path: `Text::new("Path (e.g., src/client/):").prompt()?`
   - If empty, print "Aborted." and return Ok.
3. Normalize path: ensure trailing slash (Pitfall 5 from RESEARCH.md):
   ```rust
   let path = if path.ends_with('/') { path } else { format!("{}/", path) };
   ```
4. Load current config: `config::load_config()?` → get `(cfg, _warnings)`.
5. Get mutable aliases from config (or create empty HashMap).
6. Insert the new alias: `aliases.insert(name.clone(), path.clone())`.
7. Save config: Call `config::save_ezpm_toml(...)` with all config values. Extract project_name, src, darklua_build from loaded config with defaults.
8. Auto-regenerate: Call `config_gen::write_config_files(Path::new("."), &aliases)?` (CONTEXT.md locked decision: auto-regenerate after every add/remove).
9. Optionally create directory if it does not exist:
   - If `!Path::new(path_no_slash).exists()`:
     - `Confirm::new(&format!("Create directory '{}'?", path_no_slash)).with_default(true).prompt()?`
     - If confirmed: `std::fs::create_dir_all(path_no_slash)?`
10. Print: `"Added alias @{name} -> {path}"`

**`pub fn alias_remove() -> Result<()>`** (CFG-03):
Implements CONTEXT.md "multi-select checklist of all aliases — user can select multiple to remove at once":

1. Load current config: `config::load_config()?`.
2. Get aliases from config. If empty, print "No aliases configured." and return Ok.
3. Build sorted label list: `"{name} -> {path}"` for each alias, sorted alphabetically by name.
4. Present `MultiSelect::new("Select aliases to remove:", labels).prompt()?` (CONTEXT.md: multi-select checklist).
5. If selection is empty, print "No aliases selected." and return Ok.
6. Extract alias names from selected labels (split on " -> ", take first part).
7. Confirm removal: `Confirm::new(&format!("Remove {} alias(es)?", selected.len())).with_default(false).prompt()?`
8. If not confirmed, return Ok.
9. Remove selected aliases from the HashMap.
10. Save config with updated aliases (same as alias_add step 7).
11. Auto-regenerate .darklua.json and .luaurc.
12. Print: `"Removed {n} alias(es)."` listing each removed name.

Add `pub mod alias;` to `rust-src/commands/mod.rs`.
