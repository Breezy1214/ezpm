```rust
fn is_tool_available(tool: &str) -> bool {
    std::process::Command::new(tool)
        .arg("--version")
        .output()
        .map(|o| o.status.success())
        .unwrap_or(false)
}
```
Uses `.output()` to capture silently (Pitfall 4 from RESEARCH.md).

**2. `pub fn install_tools(src_prefix: &str) -> Result<()>`**:
- Print "Installing development tools..."
- Run `rokit install` using `.status()` (pass-through so user sees real-time output — Pitfall 4).
- If rokit fails, return error.
- Check if `wally.toml` exists in current directory (INST-02).
- If wally.toml exists:
  - Run `wally install` using `.status()` pass-through.
  - If wally install succeeds, run `wally-package-types --sourcemap sourcemap.json Packages` using `.status()`.
  - Also run for `ServerPackages` directory if it exists after wally install (INST-03).
- Print "All tools installed successfully!" on completion.
- Return `Ok(())`.

**3. `pub fn setup_wally_packages(src_prefix: &str) -> Result<()>`** (INST-04):
- Check `wally.toml` exists; if not, print "No wally.toml found, skipping." and return Ok.
- Remove `sourcemap.json` if exists.
- Remove `wally.lock` if exists.
- Remove `Packages/` and `ServerPackages/` directories if they exist.
- Run `wally install` using `.status()`.
- Run `rojo sourcemap . -o sourcemap.json` using the existing `services::sourcemap::generate_sourcemap` function. Import it.
- For each package dir (`Packages`, `ServerPackages`): if dir exists after install, run `wally-package-types --sourcemap sourcemap.json <dir>` using `.status()`.
- Run sourcemap generation again (matching Luau behavior).
- Print "Setup complete!".

Add `pub mod install;` to `rust-src/commands/mod.rs`.

Use `anyhow::{Context, Result}` for error handling. Use `std::path::Path` for file existence checks.

Match the Luau `toolchain.luau` behavior: `installTools` runs rokit then optionally wally; `setupWallyPackages` does the full clean-reinstall cycle.

**2. `pub fn lint(src_path: &str) -> Result<()>`** (QUAL-01, QUAL-02):
- Check if selene is available. If not, print "Skipping Selene (not installed)".
- Check if stylua is available. If not, print "Skipping StyLua (not installed)".
- If neither tool is available, print "No linting tools installed." and return Ok (graceful skip — QUAL-02).
- If selene is available: run `selene <src_path>` using `.status()` (pass-through so user sees lint output).
  - If selene fails (non-zero exit), print "Selene linting found issues" but continue to stylua.
- If stylua is available: run `stylua --check <src_path>` using `.status()`.
  - If stylua fails, print "StyLua formatting issues found. Run `ezpm format` to fix."
- If both pass, print "All code quality checks passed!".
- Return Ok (lint issues are reported but don't return Err — matching Luau behavior where lint just reports).

**3. `pub fn format_code(src_path: &str) -> Result<()>`** (QUAL-03):
- Check if stylua is available. If not, print "StyLua is not installed. Install with: rokit add JohnnyMorganz/StyLua@2.3.1" and return Ok (graceful skip).
- Run `stylua <src_path>` using `.status()` (pass-through).
- If succeeds, print "Code formatted successfully!".
- If fails, return error.

**4. `pub fn docs(docs_enabled: bool) -> Result<()>`** (QUAL-04):
- If `!docs_enabled`, print "Documentation is not set up for this project. Set `docs_enabled = true` in ezpm.toml [display] section." and return Ok.
- Run `moonwave dev` using `.status()` (pass-through — it is a long-running server).
- This is a blocking call; user exits with Ctrl-C.

Add `pub mod quality;` to `rust-src/commands/mod.rs`.

Use `anyhow::{Context, Result}` and `std::process::Command`. Match the Luau `toolchain.luau` behavior for `runLinting`, `formatCode`, and `openDocumentation`.
