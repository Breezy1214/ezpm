**Gap being closed:** VERIFICATION.md gap — "Commands::FixRequires arm prints placeholder message instead of calling services::require_fixer::fix_requires()"

**Step 1: Add required imports to main.rs**

Add `use ezpm::services::require_fixer;` at the top of main.rs alongside existing imports.

**Step 2: Restructure the command dispatch in main.rs**

The current main.rs has a single `match cli.command` that sends ALL commands to a generic placeholder. Replace the `Commands::FixRequires` arm with a dedicated handler that:

1. Loads config using `config::load_config()` (already done at the top of main — reuse the result by moving config loading before the match and storing it)
2. Extracts aliases from config: `config.aliases.unwrap_or_default()`
3. Determines the source prefix from config: `config.paths.as_ref().and_then(|p| p.src.as_deref()).unwrap_or("src")`
4. Determines the root directory: use `std::env::current_dir()` (the project root)
5. Calls `require_fixer::fix_requires(&root_dir, &aliases, src_prefix)`
6. Handles the Result:
   - On success: display output per CONTEXT.md format decisions
   - On error: print error to stderr and exit with non-zero code

**Step 3: Implement the output display per CONTEXT.md locked decisions**

The CONTEXT.md specifies this exact output format:

- **Per-file change list:** For each `FileChange` in `result.changes`, print the file path, then for each `RequireRewrite`, print the old path and new path (e.g., `  src/client/module -> @Client/module`)
- **Summary line at the end:** `"Fixed N requires across M files"` (where N = total rewrites across all files, M = result.files_changed)
- **When no changes found:** `"All requires up to date. 0 changes across N files."` (where N = result.total_files_scanned)
- **Only show files with actual changes** — no output for skipped/unchanged files

Example output format:
```
src/client/init.luau:
  src/shared/utils -> @Shared/utils
  src/server/api -> @Server/api
src/server/main.luau:
  src/client/types -> @Client/types

Fixed 3 requires across 2 files
```

Or when no changes:
```
All requires up to date. 0 changes across 15 files.
```

**Step 4: Keep other commands on the placeholder**

All other commands (Serve, Init, Install, Lint, Format, Docs, SetupWallyPackages, Alias) should remain on the existing placeholder message. Only FixRequires gets wired up in this gap closure.

**Step 5: Error handling**

- If `fix_requires()` returns an `Err`, print the error to stderr with `eprintln!("Error: {}", e)` and exit with `std::process::exit(1)` (per CONTEXT.md: non-zero for actual errors)
- If `fix_requires()` succeeds but had warnings (e.g., relative paths), those are already handled inside the engine — the caller just needs to display the FixResult

**Implementation note:** The current main.rs loads config at startup but discards the result (only prints warnings). Refactor to store the config in a variable so the FixRequires handler can access `config.aliases`. Keep the warning printing behavior for all commands.
