**output.rs — add error_block() function:**

Add a new public function `error_block(error: &str, context: &str, fix: Option<&str>)` to output.rs after the existing `error()` function. This function prints a structured three-section block to stderr:

```rust
pub fn error_block(error: &str, context: &str, fix: Option<&str>) {
    eprintln!(
        "{} {}",
        "Error:".if_supports_color(Stream::Stderr, |t| t.red().bold()),
        error
    );
    eprintln!(
        "{} {}",
        "Context:".if_supports_color(Stream::Stderr, |t| t.yellow().bold()),
        context
    );
    if let Some(fix_msg) = fix {
        eprintln!(
            "{} {}",
            "Fix:".if_supports_color(Stream::Stderr, |t| t.green().bold()),
            fix_msg
        );
    }
}
```

Key rules per CONTEXT.md locked decisions:
- error_block() ALWAYS prints (not suppressed by --quiet) — same contract as error()
- Uses existing `if_supports_color(Stream::Stderr, ...)` pattern from output.rs — automatically respects NO_COLOR and --color Never
- `fix` is `Option<&str>` — pass `None` for unknown errors where no curated fix exists

**cli.rs — add --check flag to Format variant:**

```rust

```

    /// Exit non-zero if files are unformatted, without writing changes

**quality.rs — update format_code() signature and behavior:**

Change the function signature from:
```rust
pub fn format_code(src_path: &str) -> Result<()>
```
to:
```rust
pub fn format_code(src_path: &str, check: bool) -> Result<()>
```

When `check` is true:
- In the verbose path, pass `--check` to stylua: add `.arg("--check")` before `.arg(src_path)`
- In the capture path, pass `--check` to stylua: add `.arg("--check")` before `.arg(src_path)`
- On failure in check mode, use error_block instead of bare bail:
  ```rust
  // Print captured output first (non-verbose path)
  let stderr = String::from_utf8_lossy(&stylua_out.stderr);
  if !stderr.trim().is_empty() {
      eprint!("{}", stderr);
  }
  output::error_block(
      "Format check failed",
      &format!("Unformatted files found in {}", src_path),
      Some("Run `ezpm format` to auto-fix"),
  );
  anyhow::bail!("format check failed");
  ```
- On success in check mode, print: `output::success("All files properly formatted!");`

When `check` is false (current behavior):
- StyLua runs without `--check` (in-place formatting)
- Exit 0 even when files were reformatted (rustfmt/prettier convention — reformatting is success, not failure)
- Keep existing success message "Code formatted successfully!"

Implementation approach for the dual paths: Build the StyLua Command conditionally:
```rust
let mut cmd = Command::new("stylua");
if check {
    cmd.arg("--check");
}
cmd.arg(src_path);
```
Then use cmd for both the verbose (.status()) and capture (.output()) paths. This avoids duplicating the --check logic across 4 branches.
